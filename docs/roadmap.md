## 前提：エネ管との重なりを前提に配分する

エネルギー管理士（電気分野）の課目と電験三種 機械・電力の対応。
**重なりが大きいところは「学習」ではなく「想起」で足りる。** 時間はそこから引き剥がす。

| 電験3種の単元 | エネ管の該当課目 | 重なり | 扱い |
|---|---|:---:|---|
| 機械：変圧器・誘導機・同期機・直流機 | 課目III 電気機器 | ◎ | **想起**。Lap 1 を速く回す |
| 機械：自動制御 | 課目II 自動制御及び情報処理 | ◎ | 想起 |
| 機械：照明・電熱・電気化学・電動力応用 | 課目IV 電力応用 | ◎〜○ | 想起（※課目IVは選択制。選ばなかった分野は新規） |
| 機械：パワーエレクトロニクス | 課目III / IV | ○ | 想起＋補強 |
| 機械：情報・論理回路 | 課目II 情報処理 | ○ | 想起 |
| 電力：変電・配電・力率改善・%Z・短絡計算 | 課目III **工場配電** | ◎ | **想起**。%Z は既に武器を持っている |
| 電力：送電（線路定数・中性点接地・誘導障害） | — | △ | 一部新規 |
| 電力：**水力・火力・原子力・新エネ発電** | — | ✗ | **完全に新規。ここが本丸** |
| 電力：電気材料 | 課目III の一部 | △ | 軽く |

### 配分の結論

**電力の「発電」だけが真の新規学習。** それ以外は想起で回せる。
機械を厚く見積もる一般的な配分（機械 > 電力）は、あなたには当てはまらない。
**発電（水力・火力・原子力・新エネ）に最も厚く時間を置く。**

### Lap 0【土台：磁気を戻す】2026-09-06 → 09-12（1週 / 19.5h）← 今ここ

機械のA問題主力（変圧器・誘導機・同期機・直流機）は**全部が磁気の上に乗っている**。
エネ管で機器は分かっていても、Φ→e の基礎が抜けていると今回のように詰まる。

- [ ] [`clusters/magnetism.md`](../notes/clusters/magnetism.md) の**到達判定6項目**をクリア
- [ ] 理論の磁気クラスタ ng/risky 16件を、**過去問を解く形で**思い出す（読むだけにしない）

**完了条件**：何も見ずに `Φ = Φm sin2πft` から4行で 4.44 に到達できる

> エネ管保有者なら1週で十分。**ただし飛ばさない。** ここは機械の全単元の前提。

### Lap 1【一巡：全分野を通す】2026-09-13 → 10-24（6週 / 117h）

**目安ペース：1問20分前後 / 1日7〜8問。** 300〜400問で6週に収まる。

- 分野別過去問題集を、機械 → 電力 の順で通す（[重なりマップ](#前提エネ管との重なりを前提に配分する)より機械が先）
- **3分考えて手が動かなければ即解答へ**。粘らない。粘るのは Lap 2 以降
- Check 欄の1つ目を必ず埋める（〇 / ✗）
- ✗ だった問題は分野と原因をメモする。**原因の分類が Lap 2 の設計になる**
- [ ] 機械：[`machine-checklist.md`](../notes/machine-checklist.md) を一巡
- [ ] 電力：[`power-checklist.md`](../notes/power-checklist.md) を一巡
- [ ] **発電（水力・火力・原子力・新エネ）は新規範囲**。ここだけは解説を丁寧に読む

**完了条件**：両科目とも全分野の Check 1回目が埋まり、✗ の一覧ができている

### Lap 2【弱点潰し】2026-10-25 → 11-28（5週 / 97.5h）

**Lap 1 で ✗ だった問題だけを解く。〇 は触らない。**

- ✗ の原因を3つに分類し、対処を変える
  - **知識欠落**（そもそも知らない）→ 単元を読み込む
  - **想起失敗**（知っているが出てこない）→ 反復回数を増やす
  - **手順ミス**（分かっているが計算で落とす）→ 手順を書き出して型にする
- 同じ物理法則の ✗ が3件を超えたら `notes/clusters/` に1本立てる
- 詰まったものは `mistakes/weak_points.md` へ

**完了条件**：Lap 1 の ✗ の8割が閉本で解ける

### Lap 3【全問2周目・閉本】2026-11-29 → 2027-01-09（6週 / 117h）

**〇 も含めて全問をもう一度。ただし閉本・時間を意識して。**

- Check 欄の2つ目を埋める
- Lap 1 で 〇 だったのに落とすものが必ず出る。**それが本当の弱点**
- 定着していない単元は SR（1日 → 3日 → 7日 → 14日 → 30日）で回す

**完了条件**：2周目の正答率が両科目とも70%以上

### Lap 4【年度別 通し演習 ＋ 弱点】2027-01-10 → 02-20（6週 / 117h）

**分野別だけでは本番形式に慣れない。ここで年度別に切り替える。**

- 年度別過去問を**時間を計って**通しで解く（A問題14題＋B問題3題／90分）
- 1年度解くごとに採点し、60点との差を記録する
- 落とした問題を Lap 2 と同じ方法で分類・対処
- Check 欄の3つ目を埋める

**完了条件**：直近5年分で両科目とも安定して60点を超える

### Lap 5【直前・総仕上げ】2027-02-21 → 03-27（5週 / 97.5h）
