## Phase 定義（日付ではなく「条件」で進める）

日付で区切ると、遅れた瞬間にロードマップが嘘になる。**達成条件で区切る。**

### Phase A【止血】← 今ここ

**目的：測れていないもの・回っていないものを直す。新規学習より優先。**

- [ ] 次回試験日を確定し、`EXAM_DATE` を設定する
- [ ] 期限切れ復習27件を**磁気クラスタから**消化する（16件が該当）
- [ ] `notes/clusters/magnetism.md` の到達判定6項目を全部クリアする
- [ ] 電力・機械・法規にも記録を入れ、達成率の `null` を消す（各科目 最低1件）

**完了条件**：期限切れ復習が10件以下 かつ 4科目すべてに達成率の数字が入っている

### Phase B【弱点クラスタの殲滅】

**目的：ng / risky を ok に変える。新規範囲を広げない。**

- [ ] 磁気クラスタの ng / risky を全部 ok にする
- [ ] 次に大きいクラスタを特定し、`notes/clusters/` に1本立てて同じことをする
- [ ] 週あたりの稼働日を 4日以上にする（現在 6日/28日）

**完了条件**：ng が全体の20%以下

### Phase C【全科目の面を取る】

**目的：理論偏重（29/35件）を是正する。**

- [ ] 機械：変圧器 → 誘導機 → 同期機 → 直流機 → パワエレ
- [ ] 電力：発電 → 変電 → 送配電
- [ ] 法規：denken-wiki の[分野別過去問](https://kfurufuru.github.io/denken-wiki/kakomon/by-field/)を過去問→条文の順で回す

**完了条件**：4科目すべてで達成率50%以上

### Phase D【直前仕上げ】

- [ ] 過去問10年分 全科目
- [ ] 時間配分の練習（A問題14題＋B問題3題を90分）
- [ ] 弱点集の総ざらい
