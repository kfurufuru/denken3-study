## ① 変圧器 🔴 最優先

> **理由**: 機械と電力の両方に出る。`%Z` は電力の短絡容量計算と共通の武器になる。
> 物理法則の正本 → [`clusters/magnetism.md`](clusters/magnetism.md)

### rank A

- [ ] 誘導起電力 `E = 4.44 f N Φm` と磁束 Φm の算出
- [ ] 巻数比・電圧比・電流比・インピーダンス比（a, 1/a, a²）
- [ ] 等価回路（一次換算・二次換算）と簡易等価回路
- [ ] 電圧変動率 ε = p·cosθ + q·sinθ
- [ ] 損失（無負荷損＝鉄損／負荷損＝銅損）と効率
- [ ] **最大効率の条件**（鉄損＝銅損）と全日効率
- [ ] パーセントインピーダンス %Z と短絡電流

### rank B

- [ ] 並行運転の条件と負荷分担
- [ ] 三相結線（Δ-Δ, Δ-Y, Y-Δ, Y-Y）と位相変位
- [ ] V結線（出力・利用率）
- [ ] 単巻変圧器（自己容量と線路容量）
- [ ] 無負荷試験・短絡試験からの定数決定

### rank C

- [ ] 三相-二相変換（スコット結線）
- [ ] 変圧器の冷却方式・騒音

## ③ 同期機 🔴 最優先

> **電力科目の「発電機」と同じもの。** 水力・火力・原子力の発電端はすべて同期発電機。

### rank A

- [ ] 同期速度と極数
- [ ] 等価回路・ベクトル図（同期リアクタンス Xs）
- [ ] 出力 P = (V·E/Xs)·sinδ と負荷角 δ
- [ ] 短絡比・percent 同期インピーダンス

### rank B

- [ ] 位相特性曲線（V曲線）・励磁と力率の関係
- [ ] 並行運転の条件（同期投入）
- [ ] 電機子反作用（増磁・減磁・交差磁化）
- [ ] 同期電動機の始動法・特徴

### rank C

- [ ] 同期調相機
- [ ] 突極機の二反作用理論
