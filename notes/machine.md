## 変圧器

### 誘導起電力の基本式 E = 4.44 f N Φm

#### 導出（暗記ではなく毎回この4行を書けるようにする）

鉄心中の磁束が正弦波で変化しているとする。

1. **磁束**　Φ(t) = Φm sin(2πf t)　［Φm は**最大値**］
2. **ファラデー**　e(t) = N・dΦ/dt = 2πf N Φm・cos(2πf t)
3. **起電力の最大値**　Em = 2πf N Φm
   → 微分で出てくるのは**最大値どうしの関係**。ω = 2πf を掛けるだけ。
4. **実効値へ**　E = Em/√2 = (2π/√2)・f N Φm ≒ **4.44 f N Φm**

#### 逆に解いて磁束を求める形

    Φm = (√2 / 2π) · V1 / (f N1)  ≒ (1/4.44) · V1 / (f N1)    ［V1 は実効値］

    √2/(2π) ≒ 1/4.44 ≒ 0.225 、 2π/√2 ≒ 4.44 、 1/(2π) ≒ 0.159

#### √2 を掛けるのか割るのかで迷ったときの一手

**実効値は最大値より必ず小さい**（正弦波なら 1/√2 ≒ 0.707 倍）。

- 最大値 → 実効値：**÷√2**（小さくする）
- 実効値 → 最大値：**×√2**（大きくする）

Φm は「磁束の**最大値**」なので、実効値 V1 から求める式では
√2 が**分子**に来る。分母に √2 が来た式を書いたら、その時点で誤り。

### 「実効値」か「最大値」か — 判定の型

電験で単に「電圧 V〔V〕」「電流 I〔A〕」と書かれていたら、**既定値は実効値**。
最大値のときは「最大値」「波高値」と必ず明示される。

判定に使える3つの根拠：

1. **銘板・定格・計器の指示値は全部実効値**
   6 300 V, 210 V, 100 V のような「切りのよい系統電圧」は実効値。
   最大値で 6 300 V などと表記する慣習はない。
2. **実効値の定義そのもの**
   実効値＝同じ抵抗に流したとき直流と同じ発熱をする値（＝二乗平均平方根）。
   **電力を計算できる値だから実効値が既定**。P = VI が成り立つのは実効値のとき。
3. **係数とのペア整合**
   - 「最大値」とペアになる係数は **1/(2π)**（Φm = V1max /(2πfN1)）
   - 「実効値」とペアになる係数は **√2/(2π)**
   このペアが崩れている選択肢は、計算せずに切れる。

### 巻数比と電流の検算

    V2/V1 = N2/N1 ,  I1/I2 = N2/N1  （電流は逆比）

**必ず電力で検算する**：V1 I1 = V2 I2。
一次と二次を取り違えると、この積が合わなくなるので即座に気づける。

> 例：N1=2550, N2=85, V1=6300 V, 二次に 7 Ω 負荷
> V2 = (85/2550)×6300 = 210 V, I2 = 210/7 = 30 A, I1 = (85/2550)×30 = 1.0 A
> 検算：6300×1.0 = 6300 W, 210×30 = 6300 W ✅
> **高圧側は電流が小さい**という物理感覚とも一致（1.0 A が一次側）。

### 電圧・周波数を変えたときの磁束

Φm ∝ V1/(f N1) なので：

- 電圧を上げる → 磁束が増える → **磁気飽和**の危険
- 周波数を下げる → 磁束が増える → 同じく飽和（60 Hz 機を 50 Hz で使うと危険）

「V/f 一定」で運転する理由がここにある。
