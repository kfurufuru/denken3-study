## ① 送電・故障計算 🔴 最優先

> **`%Z` は機械の変圧器と共通の武器。** 先に変圧器で %Z を固めると、ここが一気に楽になる。

### rank A

- [ ] パーセントインピーダンス %Z・基準容量への換算
- [ ] 三相短絡電流・短絡容量 Ps = 100/%Z × Pn
- [ ] 電圧降下の近似式 v = √3·I(R cosθ + X sinθ)
- [ ] 電力損失 と 力率の関係
- [ ] 送電電力 P = (Vs·Vr/X)·sinδ

### rank B

- [ ] 線路定数（抵抗・インダクタンス・静電容量・漏れコンダクタンス）
- [ ] 中性点接地方式（直接・抵抗・消弧リアクトル・非接地）の比較
- [ ] フェランチ効果・充電電流
- [ ] コロナ放電・多導体方式
- [ ] 誘導障害（静電誘導・電磁誘導）と対策
- [ ] 電力円線図・調相設備

### rank C

- [ ] 安定度（定態・過渡）と向上対策
- [ ] 直流送電の特徴

## ② 配電 🔴 最優先

### rank A

- [ ] 需要率・負荷率・不等率の定義と計算
- [ ] 力率改善（コンデンサ容量 Qc = P(tanθ₁ − tanθ₂)）
- [ ] 配電線の電圧降下・電力損失（末端集中負荷／分布負荷）
- [ ] 単相3線式の中性線・不平衡

### rank B

- [ ] 配電方式（放射状・ループ・スポットネットワーク）
- [ ] 高圧配電・柱上変圧器
- [ ] 保護協調（ヒューズ・リクローザ）
- [ ] 電圧調整（SVR・LRT）

### rank C

- [ ] 配電自動化

## ⑥ 変電所 🟡 重要

> **機械の変圧器と直結。** 変圧器の損失・効率・並行運転は機械側で固める。

### rank A

- [ ] 変圧器の損失と変電所の効率
- [ ] 遮断器の種類（ガス・真空）と定格遮断容量
- [ ] 調相設備（電力用コンデンサ・分路リアクトル・同期調相機）

### rank B

- [ ] 断路器・避雷器（制限電圧・公称放電電流）
- [ ] 計器用変成器（VT・CT）と二次側の取り扱い
- [ ] 母線方式

### rank C

- [ ] GIS・変電所の絶縁協調
