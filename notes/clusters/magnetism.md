# クラスタ：磁気 — 「Φが変われば e が生じる」の一本道

> **このファイルの存在理由**：records.json の要復習（ng / risky）25件のうち **16件（64%）がこのクラスタ**。
> 磁界4・電磁誘導4・電磁誘導＋インダクタンス4・電位電界磁界3。
> 科目で分けると同じ穴を理論と機械で2回掘ることになるので、**物理法則で1本に束ねる**。

---

## 幹（ここだけは絶対に落とさない）

```
コイルを貫く磁束 Φ が変化する  →  起電力 e が生じる
                                    e = -N · dΦ/dt
```

- **N** は巻数、**マイナス**はレンツの法則（変化を妨げる向き）＝向きの話だけ
- 起電力は**回路が閉じていなくても発生する**。電流が流れるかは別問題
- 大きさを問われたらマイナスは無視してよい。**向きを問われたときだけマイナスを使う**

!!! 最重要
    **Δ形（ΔΦ/Δt）では正弦波が扱えない。** 交流が絡んだ瞬間に微分形 dΦ/dt へ切り替える。
    ここを切り替えられないと、下の枝1（変圧器）に到達できない。

---

## 枝分かれ — 「何が動いているか」で4つに分かれる

| 枝 | 状況 | 式 | 主な出題先 |
|---|---|---|---|
| **1. 変圧器起電力** | 回路は静止、**磁束が時間変化** | e = -N dΦ/dt → **E = 4.44 f N Φm** | 機械（変圧器）・理論 |
| **2. 速度起電力** | 磁束は一定、**導体が動く** | **e = B L v**（v⊥B のとき） | 理論（フレミング右手）・機械（回転機） |
| **3. 自己誘導** | **自分の電流**が変化 | e = -L di/dt、W = ½LI² | 理論（インダクタンス） |
| **4. 相互誘導** | **相手の電流**が変化 | e₂ = -M di₁/dt、M = k√(L₁L₂) | 理論・機械（変圧器の原理） |

枝1と枝2は**同じ法則の別の顔**。枝1は Φ が動き、枝2は回路が動く。どちらも「鎖交磁束の時間変化」。

---

## 枝1：変圧器起電力 E = 4.44 f N Φm

### 導出（暗記ではなく、毎回この4行を書く）

1. **磁束**　Φ(t) = Φm sin(2πf t)　［Φm は**最大値**］
2. **ファラデー**　e(t) = N·dΦ/dt = 2πf N Φm·cos(2πf t)
3. **起電力の最大値**　Em = 2πf N Φm
   → 微分で出てくるのは**最大値どうしの関係**。ω = 2πf を掛けるだけ
4. **実効値へ**　E = Em/√2 = (2π/√2)·f N Φm ≒ **4.44 f N Φm**

### 磁束を求める形（逆に解く）

    Φm = (√2 / 2π) · V1 / (f N1)  ≒ (1/4.44) · V1 / (f N1)    ［V1 は実効値］

    √2/(2π) ≒ 1/4.44 ≒ 0.225 ／ 2π/√2 ≒ 4.44 ／ 1/(2π) ≒ 0.159

### √2 を掛けるのか割るのかで迷ったときの一手

**実効値は最大値より必ず小さい**（正弦波なら 1/√2 ≒ 0.707 倍）。

- 最大値 → 実効値：**÷√2**（小さくする）
- 実効値 → 最大値：**×√2**（大きくする）

Φm は「磁束の**最大値**」なので、実効値 V1 から求める式では √2 が**分子**に来る。
分母に √2 が来た式を書いたら、その時点で誤り。

### 「実効値」か「最大値」か — 判定の型

電験で単に「電圧 V〔V〕」「電流 I〔A〕」と書かれていたら、**既定値は実効値**。
最大値のときは「最大値」「波高値」と必ず明示される。判定根拠は3つ：

1. **銘板・定格・計器の指示値は全部実効値**。6 300 V のような系統電圧を最大値で書く慣習はない
2. **実効値の定義そのもの**。実効値＝同じ抵抗に流したとき直流と同じ発熱をする値（二乗平均平方根）。
   **電力を計算できる値だから実効値が既定**。P = VI が成り立つのは実効値のとき
3. **係数とのペア整合**。「最大値」↔ **1/(2π)**、「実効値」↔ **√2/(2π)**。
   ペアが崩れた選択肢は計算せずに切れる（ただしこれだけでは一意に決まらないことがある）

### 電圧・周波数を変えたときの磁束

Φm ∝ V1/(f N1) なので：

- 電圧を上げる → 磁束が増える → **磁気飽和**
- 周波数を下げる → 磁束が増える → 同じく飽和（60 Hz 機を 50 Hz で使うと危険）

「V/f 一定」で運転する理由がここにある。→ 機械の誘導電動機の可変速制御へ直結。

## 枝2：速度起電力 e = B L v

- **フレミング右手**：親指＝**動**（v）、人差し指＝**磁**（B）、中指＝**電**（e・i）
- **右が発電、左が電動**
- ローレンツ力 **F = qv×B** と同じ物理。導体中の自由電子が受ける力が電荷分離を起こし、それが起電力になる
- v と B が直交しないときは **e = B L v sinθ**

→ `records.json` の「電位・電界・磁界（ローレンツ力）」3件の ng はここ。BLv と F=qv×B を**別物として覚えている**のが原因なら、それが誤り。

## 枝3・4：インダクタンス

- 自己：**e = -L di/dt**、エネルギー **W = ½LI²**
- 相互：**e₂ = -M di₁/dt**、結合係数 **k = M/√(L₁L₂)**（0≦k≦1、理想変圧器は k=1）
- 直列：和動 **L₁+L₂+2M**／差動 **L₁+L₂−2M** → 差をとると **M = (L和−L差)/4**
- 巻数比 a = N₁/N₂ のとき **Z₁ = a²Z₂**（電圧 a 倍 × 電流 1/a 倍の比だから2乗）

> 詳細は [denken-wiki: 自己・相互インダクタンス](https://kfurufuru.github.io/denken-wiki/theory/inductance/)

## 磁気回路 — オームの法則の類推

| 電気回路 | 磁気回路 |
|---|---|
| 起電力 E〔V〕 | 起磁力 F = NI〔A〕 |
| 電流 I〔A〕 | 磁束 Φ〔Wb〕 |
| 抵抗 R = ρl/S | 磁気抵抗 Rm = l/(μS) |
| E = RI | **F = Rm Φ** |

μ が大きい（鉄心）ほど磁気抵抗が小さく、磁束が通りやすい。ギャップがあると Rm が跳ね上がる。

## このクラスタ共通の落とし穴

| 落とし穴 | 症状 | 潰し方 |
|---|---|---|
| Δ形で止まる | 正弦波が来ると手が止まる | 交流が出た瞬間に dΦ/dt へ切り替える |
| √2 の向き | 分子か分母か迷う | 「実効値＜最大値」を声に出す |
| 実効値／最大値 | 問題文の V が何か決められない | 定格・銘板・計器 = 実効値。明示なき電圧は実効値 |
| 符号のマイナス | 大きさの問題でマイナスを引きずる／向きの問題で落とす | 「大きさか向きか」を先に判定 |
| BLv と qv×B を別物扱い | ローレンツ力の問題で手が止まる | 同じ物理の別表現と理解する |
| 一次／二次の取り違え | 変圧器の電流を逆に答える | 最後に必ず **V₁I₁ = V₂I₂** を書く |
