## 機械

### [機械] 変圧器の誘導起電力（実効値と最大値の取り違え・E=4.44fNΦm の導出）
- **何が弱いか**：与えられた電圧が実効値なのか最大値なのかを判定できず、さらに E = 4.44 f N Φm を導出できないため、Φm を求める式（√2 を掛けるのか割るのか）が書けない
- **どこで間違えたか**：H20 A問題7（変圧器の誘導起電力）。(ア)実効値／最大値の選択で迷い、(イ)の係数 √2/(2π) を自力で出せなかった
- **正しくはどう考えるか**：
  1. **導出を4行で書く**：Φ = Φm sin2πft → e = N dΦ/dt = 2πf N Φm cos2πft → 最大値 Em = 2πf N Φm → 実効値 E = Em/√2 = (2π/√2) f N Φm ≒ 4.44 f N Φm
  2. **微分で出るのは最大値どうしの関係**。実効値にするには最後に ÷√2 を1回だけ通す
  3. 逆に解いて Φm = (√2/2π)·V1/(f N1)。**実効値は最大値より小さい**から、実効値から最大値 Φm へ戻す式では √2 は**分子**に来る（分母に来たら誤り）
  4. **実効値か最大値かの判定**：電験で単に「電圧 V〔V〕」なら既定は**実効値**。6 300 V のような定格・銘板・計器の値は必ず実効値。最大値なら「最大値」「波高値」と明示される
  5. **係数とのペア整合で選択肢を切る**：最大値 ↔ 1/(2π)、実効値 ↔ √2/(2π)。ペアが崩れた選択肢は計算せず除外できる（本問なら(2)(5)が即死）
  6. **一次／二次の取り違えは電力で検算**：V2 = (85/2550)×6300 = 210 V、I2 = 210/7 = 30 A、I1 = (85/2550)×30 = 1.0 A。6300×1.0 = 210×30 = 6300 W で一致。高圧側の電流が小さいという感覚とも合う → 正解(3)
- **次回どう防ぐか**：変圧器の起電力が出たら、**公式を思い出す前に Φ = Φm sin2πft から4行導出を書く**。答案に √2 が出たら「実効値は最大値より小さい」と声に出して分子・分母を確認する。巻数比の問題は最後に必ず V1I1 = V2I2 を書く
- **クラスタ**：磁気 → 正本は [`notes/clusters/magnetism.md`](../notes/clusters/magnetism.md)
- **記録日**：2026/09/06

## 法規

### [法規] B種接地工事の接地抵抗（1線地絡電流の端数処理）
- **何が弱いか**：計算で出た値をそのまま使ってしまい、規定側の丸め（端数処理）を通す手順が抜ける
- **どこで間違えたか**：R6下期 A問題4。I₁ = 1 + {(V/3)L − 100}/150 = 1.133 A まで正しく出したのに、そのまま R_B = 600 ÷ 1.133 ≒ 529 Ω としてしまった
- **正しくはどう考えるか**：
  1. V は公称電圧 ÷ 1.1（6600 V → **6 kV**、6.6 のまま使わない）
  2. L は**電線延長** = こう長 × 線条数（三相3線式・こう長20 km → **60 km**）
  3. I₁ は**小数点以下を切り上げ、2未満なら2とする**（解釈17条）→ 1.133 A → **2 A**
  4. 分子は遮断時間で選ぶ：自動遮断なし 150 ／ 2秒以内 300 ／ **1秒以内 600**
  5. R_B = 600 ÷ 2 = **300 Ω**（正解(4)）
- **次回どう防ぐか**：I₁ を出したら電卓を置く前に「切り上げ・最低2A」を声に出して確認する。地絡電流が絡む問題は「計算 → 丸め → 代入」の3手順をセットで書く
- **記録日**：2026/08/18
